Agentic AI Engineer Intern

● Applications Open Summer 2026 2 Months India · Remote-first Internship

You’ll spend eight weeks building AI agents that reason, call tools, manage memory, and actually complete tasks — not demo bots that look impressive for thirty seconds before hallucinating their way into a stack trace. Real systems. Real prod. Real accountability.

Beyond the core agent work, you’ll contribute to internal platforms we use day-to-day: automation pipelines, analytics tooling, operational dashboards. Nothing gets shelved. If you build it, it runs.

What you’ll actually build
  • Multi-step agentic pipelines that plan, execute, and self-correct across dynamic inputs
  • Tool integrations: REST APIs, databases, document parsers, web retrieval, file systems
  • Memory architectures — vector stores for retrieval, session context, and long-term state
  • Evaluation harnesses so you know when your agent is right and when it’s confidently wrong
  • Guardrails and fallback logic so agents fail gracefully instead of catastrophically
  • Additional internal platform modules in automation, analytics, and operational tooling
Stack you’ll touch weekly
Python FastAPI LangChain LangGraph OpenAI API Anthropic API PostgreSQL Qdrant / Chroma Docker GitHub Actions TypeScript / JS
Weekly learning track (included)
  • Agent design patterns: ReAct, plan-and-execute, reflection loops, multi-agent coordination
  • Prompt engineering that survives contact with real users
  • Evaluation strategies: LLM-as-judge, semantic similarity, task-completion benchmarks
  • System design for AI products: latency, reliability, cost tradeoffs
  • Mentor checkpoints every week — not once at the start and once at the end
Who we’re looking for
  • Someone who ships first and polishes second.
  • You ask why before you ask how.
  • You’ve debugged a broken function call at odd hours and found it satisfying.
  • You are keen to build AI systems that are actually reliable than building ones that are merely impressive.

Prior experience with agents, LLMs, or tool orchestration is a bonus — not a requirement. We care more about how you think than what’s already on your resume.
